# 同桌 · ChipRoom

朋友线下发牌，各自在手机上记录筹码。打开 [筹码桌](https://chiproom-table-jrl.bronzybug4.chatgpt.site/) 创建房间，或通过朋友的邀请链接加入。线上版使用云端服务，玩家可以使用不同网络。

## 开桌

1. 输入昵称创建房间，分享邀请链接或房间码。
2. 房主设置起始筹码、大小盲。玩家按现实中的顺时针顺序调整座位。
3. 房主开始本手。页面显示当前行动人、底池、筹码和合法的行动金额。
4. 全桌弃到一人时自动派奖。摊牌时现场比牌，房主为主池及各边池分别勾选赢家，可多人平分。
5. 房主开下一手后自动轮换庄位。刷新或重新打开原浏览器可恢复座位。

## 实现与开发

云端入口为 `worker.mjs`，D1 保存房间、座位凭证摘要和版本号。写入使用版本条件防止重复扣筹码，前端定时获取最新状态。房间凭证保存在各自浏览器中。

需要 Node.js 22 或更高版本。项目无需安装运行依赖。

```sh
npm test
npm start
npm run build
```

`npm start` 启动开发服务，默认端口 4174，数据存放在被 Git 忽略的 `data/`。云端构建打包网页与共享规则引擎到 `dist/server/index.js`。部署使用名为 `DB` 的 D1 绑定，并应用 `drizzle/` 中的迁移。

行动和盲注规则参考 [PokerStars 规则说明](https://www.pokerstars.com/help/articles/poker-rules-master/)。
