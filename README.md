# 同桌 · ChipRoom

朋友线下发牌，各自在手机上记录筹码。打开 [筹码桌](https://jerryliruijie.github.io/ChipRoom/) 创建房间，或通过朋友的邀请链接加入。线上版使用云端服务，玩家可以使用不同网络。

单人可以直接试三种局面：[面对盲注](https://jerryliruijie.github.io/ChipRoom/?practice=call)、[前位过牌](https://jerryliruijie.github.io/ChipRoom/?practice=check)、[短码全下](https://jerryliruijie.github.io/ChipRoom/?practice=allin)。体验和多人房间共用下注引擎、操作栏与 Three.js 桌面。每个示例可以做一次决定，再重试或切换局面。

## 开桌

1. 输入昵称创建房间，或在公开大厅选择朋友的牌桌。大厅每四秒刷新，列出过去 24 小时内创建、尚未开局且有空座的新桌。新房间使用四位数字码，开头的 0 也需要输入。点桌头的号码可复制房间码，点「复制邀请」可分享链接。旧六位码及邀请链接继续有效。
2. 房主设置起始筹码、大小盲。玩家按现实中的顺时针顺序调整座位。
3. 房主开始本手。页面显示当前行动人、底池、筹码和合法的行动金额。
4. 全桌弃到一人时自动派奖。摊牌时现场比牌，房主为主池及各边池分别勾选赢家，可多人平分。
5. 房主开下一手后自动轮换庄位。返回大厅后，房主和玩家都可从「我的牌桌」以原身份回桌；已开局或坐满也能恢复。重新打开同一浏览器仍有效，前提是保留了该网站的数据。

## 下注与全下

翻牌前、翻牌圈、转牌圈和河牌圈开始时，每个玩家会看到两秒阶段提示。桌头持续显示当前阶段。手机竖持时桌面横向排列，加注选项在桌面下方展开。

1–5 BB 按本轮下注总额计算。面对下注时，半池与满池先补齐跟注，再按跟完的底池计算加注量，半个筹码四舍五入。例如盲注 10/20、底池 30、自己尚未投入时，3 BB 是加到 60，半池是加到 45，满池是加到 70。每个快捷键显示目标金额，不合规则的金额会变灰，所有选择都需要最后确认。

采用无限注德州扑克的大小盲下注结构。翻前还差筹码时可弃牌、跟注，有加注权时可加注。大盲面对全桌平跟可过牌或加注。翻后前面无人下注时可过牌或下注。加注框中的金额是本轮下注总额，选择「全下」后仍需点击确认。

下盲注、跟注或主动下注耗尽筹码时，牌桌标出全下座位。音效可在桌内开启。服务端验证轮次、应跟金额和加注范围，并按每位玩家的行动分别判断短全下是否重开加注权。摊牌时根据各底池的入围名单，在现场比牌并选择赢家。

## 实现与开发

云端入口为 `worker.mjs`，D1 保存房间、座位凭证摘要和版本号。写入使用版本条件防止重复扣筹码，前端定时获取最新状态。房间凭证保存在各自浏览器中。

需要 Node.js 22 或更高版本。项目无需安装运行依赖。

```sh
npm test
npm start
npm run build
```

`npm start` 启动开发服务，默认端口 4174，数据存放在被 Git 忽略的 `data/`。云端构建打包网页与共享规则引擎到 `dist/server/index.js`。部署使用名为 `DB` 的 D1 绑定，并应用 `drizzle/` 中的迁移。

行动和盲注规则参考 [PokerStars 规则说明](https://www.pokerstars.com/help/articles/poker-rules-master/)。
